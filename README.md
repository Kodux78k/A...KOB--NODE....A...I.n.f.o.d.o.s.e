def verify_all(json_ref_path: Path, strict: bool=False):
    ref = json.loads(json_ref_path.read_text(encoding="utf-8"))
    resultados = []
    ok = 0
    divergentes = 0
    ausentes = 0
    for item in ref.get("arquivos", []):
        path = Path(item["path"])
        esperado_md5 = item["md5"]
        esperado_sha = item["sha256"]
        if not path.exists():
            ausentes += 1
            resultados.append({
                "nome": item.get("nome"),
                "path": str(path),
                "status": "ausente"
            })
            continue
        b = path.read_bytes()
        atual_md5 = md5sum(b)
        atual_sha = sha256sum(b)
        if atual_md5 == esperado_md5 and atual_sha == esperado_sha:
            ok += 1
            resultados.append({
                "nome": item.get("nome"),
                "path": str(path),
                "status": "ok",
                "bytes": len(b)
            })
        else:
            divergentes += 1
            resultados.append({
                "nome": item.get("nome"),
                "path": str(path),
                "status": "divergente",
                "bytes": len(b),
                "md5_atual": atual_md5,
                "sha256_atual": atual_sha,
                "md5_esperado": esperado_md5,
                "sha256_esperado": esperado_sha,
            })
    saida = {
        "verificacao": "verify-all",
        "json_ref": str(json_ref_path),
        "tema_ref": ref.get("tema", {}),
        "resumo": {
            "ok": ok,
            "divergentes": divergentes,  # não inclui ausentes
            "ausentes": ausentes
        },
        "strict": strict,
        "itens": resultados,
        "exit_code": (5 if strict and ausentes>0 else (4 if divergentes>0 else 0))
    }
    return saida

resultado = verify_all(ref_path, strict=False)

🔵 1. Definição Técnica
Bluetooth é um padrão de comunicação sem fio de curto alcance baseado em ondas de rádio na faixa de 2,4 GHz, utilizado para troca de dados entre dispositivos eletrônicos pessoais, como smartphones, fones de ouvido, computadores, sensores e dispositivos embarcados, sem a necessidade de cabos físicos.
Foi originalmente desenvolvido em 1994 pela Ericsson, e posteriormente padronizado pelo Bluetooth Special Interest Group (SIG), um consórcio global de empresas de tecnologia.

🧩 2. Arquitetura do Sistema
A tecnologia Bluetooth utiliza uma arquitetura mestre-escravo (controller-host) dentro de uma topologia chamada piconet, com as seguintes características:
Camada
Função
PHY (Physical)
Transmissão de ondas de rádio em 2,402 GHz até 2,480 GHz
Baseband
Controle de tempo e acesso ao canal; define slots de 625 μs
LMP
Link Manager Protocol: autenticação, emparelhamento, controle de link
L2CAP
Logical Link Control and Adaptation Protocol: fragmentação de pacotes
SDP
Service Discovery Protocol: descoberta de serviços e perfis suportados
Aplicação
Interfaces de usuário e serviços personalizados (ex: A2DP, HFP, HID)

⚙️ 4. Funcionamento Prático
O funcionamento do Bluetooth pode ser resumido em quatro etapas:
Descoberta: Um dispositivo busca por outros que estejam visíveis no espectro de 2,4 GHz.
Emparelhamento (Pairing): Troca de chaves criptográficas para autenticação e segurança.
Conexão: Estabelecimento de canal lógico para troca de dados.
Transmissão de Dados: Fluxo bidirecional de informações, com gerenciamento de pacotes, retransmissões e encerramento controlado da conexão.

🔒 5. Segurança e Criptografia
Bluetooth utiliza diversos mecanismos para garantir confidencialidade, integridade e autenticação, incluindo:
PIN codes e chaves de autenticação
AES-CCM (Counter with CBC-MAC) como padrão de criptografia
Address randomization (MAC temporário para evitar rastreamento)
A segurança é relativa à versão e à qualidade da implementação. Versões mais antigas são vulneráveis a ataques como Bluejacking, Bluesnarfing e Man-in-the-Middle.

🧠 6. Aplicações Contemporâneas
Bluetooth é fundamental para a chamada computação ubíqua e dispositivos wearables. Aplicações modernas incluem:
Fones de ouvido e caixas de som sem fio
Rastreamento de localização (beacons)
Comunicação entre sensores biomédicos e apps de saúde
Internet das Coisas (IoT)
Gamepads, teclados, mouses
Carros conectados (Bluetooth HFP, A2DP, MAP)
